My project is a Personal Expense Tracker developed using Python. It allows users to record and manage their daily expenses. The user can add an expense by entering the amount, category, and description. The application stores the expenses and provides options to view all expenses, calculate the total amount, search expenses by category, and delete an expense using its ID.

This project is built using Object-Oriented Programming (OOP) concepts in Python, including classes, objects, inheritance, encapsulation, and polymorphism. The modular design makes the application easy to maintain and extend with future features such as monthly reports, expense summaries, budget limits, and data export functionality.

Key Features

Add new expenses with amount, category, and description

View all saved expense records

Calculate the total expenses

Search expenses by category

Delete expenses using a unique ID

Input validation for accurate data entry

Built using Python OOP principles
